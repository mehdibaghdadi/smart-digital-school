# Code of Conduct

We are committed to a welcoming, harassment-free experience for everyone.

## Expected behaviour
- Be respectful and constructive.
- Accept feedback gracefully and focus on what is best for the project.
- Show empathy toward other community members.

## Unacceptable behaviour
- Harassment, insults, discrimination or personal attacks.
- Publishing others' private information.
- Any conduct that would be inappropriate in a professional setting.

## Enforcement
Maintainers may remove, edit or reject contributions that violate this code and may ban repeat offenders. Report issues to `contact@eware.dev`.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
