# Contributing

Thanks for your interest in Smart Digital School!

## Workflow

1. Fork the repository and create a branch: `feature/<short-name>` or `fix/<short-name>`.
2. Copy the `*.example` configuration files as described in the [README](README.md). Never commit real secrets.
3. Make focused changes and make sure the affected service builds (`dotnet build`, `npm run build`, or run the Python app).
4. Write clear commit messages (e.g. `fix(payment): handle empty RIB`).
5. Open a pull request describing the change and how you tested it.

## Code style

- C#: follow standard .NET conventions.
- Python: follow PEP 8.
- TypeScript/React: keep components small and typed.

## Reporting bugs and ideas

Open an issue with steps to reproduce, expected and actual behaviour. For security issues see [SECURITY.md](SECURITY.md).
